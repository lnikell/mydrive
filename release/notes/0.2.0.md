# MyDrive 0.2.0

- Manage multiple SMB shares as separate Finder locations.
- Add and reconnect drives from a compact native window.
- Paste an SMB share URL or use a server name with the default SMB port.
- Free downloaded space or disconnect each drive independently.
- Upload, edit, rename and move ordinary files with durable recovery receipts and conflict preservation.
- Preserve pending local work when disconnecting, and find it again after restarting MyDrive.
- Prepare all drives for uninstallation with one action, evicting downloads and preserving unfinished local work. Incomplete cleanup leaves the drive connected for retry.
- Verify a new development drive before revealing its Finder location.
- Prepare verified native updates through Sparkle and local GitHub release scripts.

Development preview for Apple silicon Macs running macOS 15 or later. Package-document creation and mutation remain refused pending qualification. An official binary release requires Apple signing, provisioning, notarization and an installed update test. Use Uninstall MyDrive… before deleting the app to reclaim clean downloads; pending local work is retained. Native checks covered two drives' hydrated files and the corrected quit/reveal/Trash sequence.
