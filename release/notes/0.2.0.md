# MyDrive 0.2.0

- Manage multiple SMB shares as separate Finder locations.
- Add and reconnect drives from a compact native window.
- Free downloaded space or disconnect each drive independently.
- Receive verified native updates through Sparkle and GitHub Releases.

This is an early read-only release for Apple silicon Macs running macOS 15 or later. Remote editing and uploads are not available yet. Use Disconnect & Remove Local Downloads before deleting the app to reclaim its managed downloads. Finder may retain files in use and preserves pending local work.
